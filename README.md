# Ride guide

An unofficial, family-made comfort guide to the rides at Walt Disney World: every ride scored for motion and heights, with live wait times, a map and a one-page summary for each.

Live site: https://pjones7-del.github.io/ride-guide/

- `index.html` holds the whole app (styles, script and ride data inline).
- `img/` photos are from Wikimedia Commons under free licenses. Credits are listed on the Method tab of the site.
- `vendor/` is Leaflet 1.9.4 (BSD 2-Clause). `fonts/` is Barlow and Barlow Condensed (SIL Open Font License).
- Live wait times come from themeparks.wiki. Map tiles come from OpenStreetMap contributors.
